# Rehan College Calculator

A sleek, mobile-friendly calculator built for Rehan College.

## Features

- Basic operations: +, −, ×, ÷
- Percentage (%), Toggle sign (+/−), Delete digit (⌫)
- Live expression display while typing
- Result shown in main display on = or Enter
- Calculation History (clock icon) — click any item to reuse
- Full keyboard support
- No dependencies — pure HTML/CSS/JS

## Button Layout

```
AC    ⌫    +/-   ÷
7     8     9    ×
4     5     6    −
1     2     3    +
%     0     .    =
```

## Run Locally

Just open `index.html` in any browser — no server needed.

## Deploy to GitHub Pages

1. Upload this repo to GitHub
2. Go to **Settings → Pages**
3. Source: `main` branch, root `/`
4. Live at: `https://yourusername.github.io/rehan-calculator`
